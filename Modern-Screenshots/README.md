## How to capture screenshots:

1. Deploy the application using `./deploy.sh`
2. Navigate to the application URL at `https://<your-app>.azurewebsites.net/Index`
3. Take screenshots of each page listed above
4. Save them in this folder with the suggested filenames
5. Update this README.md with actual screenshot descriptions
